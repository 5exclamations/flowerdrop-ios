# Подготовка к App Store

Самоаудит на 1 августа 2026 по App Review Guidelines и чек-листу App Store
Connect для нашего случая: маркетплейс, оплата вне приложения за физический
товар, вход по одноразовому коду.

Статусы: **код** — закрыто в репозитории, ничего делать не надо;
**человек** — код готов, но нужно действие в App Store Connect или на боевом
хосте; **спорно** — трактовка неочевидна, решение за человеком.

## Гайдлайны

| Требование | Статус | Чем закрыто / что нужно |

## App Store Connect

| Пункт | Статус | Что нужно |
|---|---|---|
| Privacy Nutrition Labels | человек | Заполнить в точности как в `PrivacyInfo.xcprivacy`: Phone Number и Purchase History, обе привязаны к пользователю, обе только App Functionality, трекинг — нет. Расхождение манифеста и лейблов ловится на ревью |
| Privacy Policy URL | человек | `https://<боевой хост>/privacy` |
| Terms of Use (EULA) | человек | `https://<боевой хост>/terms` — либо оставить стандартный EULA Apple |
| Демо-аккаунт для ревью | код | Не требуется: ревьюер входит своим Apple ID или Google-аккаунтом |
| Google OAuth в production | **человек** | Обязательно перевести из testing mode в production, иначе Google пустит только тест-юзеров, и ревьюер получит отказ |
| Кнопка Google | код | Официальная кнопка из brand kit Google, светлый и тёмный варианты. Подпись на ней английская: локализованных вариантов Google не поставляет |
| Support URL | человек | Нужен адрес страницы поддержки; сейчас есть только `SUPPORT_EMAIL` |
| Возрастной рейтинг, описание, ключевые слова, скриншоты | человек | Заполняется в Connect |
| Export compliance | код | `ITSAppUsesNonExemptEncryption = NO`: только системный HTTPS. Вопрос на каждой сборке больше не задаётся |
| Версия и билд | код | `CFBundleShortVersionString = 1.0.0`, `CFBundleVersion = 1` |
| Локализации приложения | код | ru и az в `CFBundleLocalizations`. Локализацию страницы в Connect заполняет человек |

## Что должно быть на боевом хосте до подачи

- `SECRET_KEY`, `ALLOWED_HOSTS` — прод падает без них намеренно.
- `SUPPORT_EMAIL` — иначе на `/privacy` и `/terms` останется `support@example.com`.
- `APPLE_BUNDLE_ID` и `GOOGLE_IOS_CLIENT_ID` — пустое значение означает, что
  соответствующий вход отвергается целиком.
- HTTPS на `api.flowerdrop.az`: релизный `Info.plist` не содержит исключений ATS,
  и по HTTP приложение работать не будет — это сделано намеренно.
- Контент лавок. Названия и описания букетов приходят из API одним языком; в
  азербайджанском интерфейсе они остаются русскими. Это не блокирует ревью,
  но выглядит небрежно на скриншотах для az-локали.

## Чего в приложении намеренно нет

- Геолокации. `CoreLocation` не используется, координаты не отправляются,
  `NSLocation*`-ключей в `Info.plist` нет — добавлять их без реального
  использования нельзя.
- Аналитики, рекламных SDK, трекинга, сборщика крешей.
- Сторонних зависимостей вообще.
