# FlowerDrop — iOS client

## Project
Маркетплейс «вчерашних» букетов со скидкой -50% (Баку).
SwiftUI, iOS 17+. Backend: Django REST (позже; пока моки).

## Автономность
- Проект через XcodeGen: правь project.yml, после изменения списка
  файлов запускай xcodegen generate. НИКОГДА не трогай .pbxproj.
- Build/run/test/скриншоты — только через XcodeBuildMCP.
- Цикл фичи: код → xcodegen → build → запуск на симуляторе
  iPhone 16 → скриншот → сам сверь с ТЗ → фикси до зелёного.
- Задача закрыта = билд зелёный, 0 warnings, скриншот соответствует.

## Architecture
- SwiftUI + MVVM, async/await, URLSession, без сторонних зависимостей
- Features/<Name>/{View, ViewModel, Models}, Core/DesignSystem,
  Core/Network (APIClient за протоколом, сейчас MockAPIClient)
- Все строки в Localizable.xcstrings (ru + az)
- UI-код @MainActor, без DispatchQueue

## Design (при конфликте со скиллами этот раздел главнее)
Стиль: тёплый ботанический premium — флористический бутик,
не техно-стартап.

Токены (магические значения запрещены):
- Фон #FAF7F2 / dark #141210; карточки #FFFFFF / #1C1A17
- Акцент: глубокий зелёный #1F3D2B; вторичный: терракота #C4553B
- Радиус один на всё приложение: 20pt, .continuous
- Сетка отступов 8pt (4/8/12/16/24/32)
- Максимум 3 значения opacity

Типографика:
- Заголовки .fontDesign(.serif), вес .semibold
- Остальное SF Pro, шкала 34/22/17/15/13
- Цены .monospacedDigit()

Запрещено (анти-ИИ-слоп):
- Дефолтный синий tint, фиолетовые/радужные градиенты
- Эмодзи вместо иконок; только SF Symbols, один вес
- Тень поверх тени, карточка в карточке
- Дефолтный вид List для ленты

Паттерны:
- Photo-first: фото 4:5 edge-to-edge, тёмный скрим снизу,
  цена и дедлайн поверх фото
- Скелетоны при загрузке, задизайненные empty states
- Haptic на ключевые действия, spring-анимации
- Тёмная тема через семантические цвета с первого дня
