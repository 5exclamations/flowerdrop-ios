## 3. Незакрытые проблемы
- **Окно самовывоза у сидов протухает за час-два.** После этого `GET /api/bouquets/`
  отдаёт `[]` и лента показывает empty state. Дважды из-за этого сняты пустые
  экраны. Перед каждым прогоном обязательно:
  `cd ../flowerdrop-backend && docker compose exec -T web python manage.py seed_demo`.
- **Прогон az не закончен.** Файл `scratchpad/loc/az-06-sheet.png` по факту
  содержит экран букета, а не sheet: тапы по вводу телефона/кода не прошли.
  Надо повторить путь и проверить перенос строк в `ReserveConfirmationSheet`
  (строки «Götürmə vaxtı» / «Cəmi» и адрес справа) и в `ReservationSuccessView`
  («Kodu dükanda deyin — buketi %@-dək saxlayırıq»).
- **Контент бэкенда только на русском.** Названия и описания букетов приходят
  из API одним языком, в az-интерфейсе видны русские «Кустовые розы». Полей
  под языки в API_CONTRACT.md нет — это задача бэкенда, не клиента.
- **Множественные числа в ru не сделаны.** Ключ `осталось %lld` без вариаций,
  «осталось 1» грамматически хромает. В az вариации не нужны.
- Переводы писал не носитель языка — нужна вычитка живым человеком.

## 4. Решения, которых нет в коде
- **Регистр в az:** кнопки — короткий императив («Rezerv et», «Kodu göndər»),
  фразы — вежливое «siz» («yoxlayın», «qayıdın»). Так в Wolt/Bolt AZ. Раньше
  было вперемешку с калькой с русского — переписано.
- **Флаг онбординга в `@AppStorage` внутри RootView**, а не в сторе: `@AppStorage`
  это DynamicProperty и в `@Observable`-классе не работает (та же причина, по
  которой AuthStore пишет в UserDefaults напрямую).
- **Локаль переключается аргументами запуска**, а не настройками симулятора:
  `xcrun simctl launch "iPhone 16" com.texa.flowerdrop -AppleLanguages "(az)" -AppleLocale az_AZ`.
  Так быстрее и не трогает состояние устройства.
- Онбординг показывается один раз на установку; чтобы увидеть его снова,
  нужен `simctl uninstall` — сброса флага в UI нет намеренно.
