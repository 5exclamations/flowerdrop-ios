## 3. Незакрытые проблемы
- **Окно самовывоза у сидов протухает за час-два.** После этого `GET /api/bouquets/`
  отдаёт `[]` и лента показывает empty state. Перед каждым прогоном обязательно:
  `cd ../flowerdrop-backend && docker compose exec -T web python manage.py seed_demo`.
  Сид печатает, до какого времени открыто окно.
- **Контент бэкенда только на русском.** Названия, описания и адреса лавок
  приходят из API одним языком, в az-интерфейсе видны русские «Кустовые розы» и
  «ул. Низами, 28». Полей под языки в API_CONTRACT.md нет — это задача бэкенда.
- **Множественные числа в ru не сделаны.** Ключ `осталось %lld` без вариаций,
  «осталось 1» грамматически хромает. В az вариации не нужны.
- **Время без ведущего нуля.** `Date.formatted(date: .omitted, time: .shortened)`
  в `Bouquet.pickupUntilText` и `Reservation.expiresAtText` даёт «3:12», а не
  «03:12». Ведёт себя так одинаково в ru и az — это не регрессия локализации,
  а поведение Foundation; на экранах с 21:00 незаметно, вылезает только ночью.
  Чинится своим форматом, если решим, что мешает.
- Переводы писал не носитель языка — нужна вычитка живым человеком.

## 4. Решения, которых нет в коде
- **Регистр в az:** кнопки — короткий императив («Rezerv et», «Kodu göndər»),
  фразы — вежливое «siz» («yoxlayın», «qayıdın»). Так в Wolt/Bolt AZ.
- **Флаг онбординга в `@AppStorage` внутри RootView**, а не в сторе: `@AppStorage`
  это DynamicProperty и в `@Observable`-классе не работает (та же причина, по
  которой AuthStore пишет в UserDefaults напрямую).
- **Локаль переключается аргументами запуска**, а не настройками симулятора:
  `xcrun simctl launch "iPhone 16" com.texa.flowerdrop -AppleLanguages "(az)" -AppleLocale az_AZ`.
- Онбординг показывается один раз на установку; чтобы увидеть его снова,
  нужен `simctl uninstall` — сброса флага в UI нет намеренно.
- **`simctl uninstall` не разлогинивает.** Токен лежит в Keychain, а Keychain
  переустановку приложения переживает — после переустановки экраны телефона и
  кода просто не показываются. Чтобы пройти авторизацию, нужен
  `xcrun simctl keychain <udid> reset` (онбординг при этом не вернётся: его флаг
  в UserDefaults, они чистятся как раз при uninstall).
